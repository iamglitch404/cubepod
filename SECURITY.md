# Security Policy

## Supported Versions

Currently, the following versions are being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within CubePod, please do not disclose it publicly.
Instead, send an email to the repository maintainers.

We will try to review the issue and acknowledge receipt within 48 hours. If the vulnerability is confirmed, we will release a patch as soon as possible.
